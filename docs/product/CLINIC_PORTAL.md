# Saxlem Clinic Portal

Sprint 12A establishes a separate, read-only receptionist web application under `clinic-portal/`. Its purpose is to make the clinic's current operational state understandable within 30 seconds. It contains a localized application shell, a mock dashboard, and honest placeholders for Patients, Appointments, Live Queue, Doctors, Schedule, Notifications, and Settings. It contains no backend, real authentication, editing, check-in, queue mutations, reports, payments, or future staff roles.

Ease of use outranks feature density. Each screen has one purpose, common destinations are one click away, and only information that supports a receptionist decision is visible.
