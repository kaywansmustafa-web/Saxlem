# Clinic Portal Design System

The web-native token layer uses Saxlem blue for trust and action, teal for medical intelligence, semantic surface/content/border roles, status foreground/background pairs, a 4px base rhythm, moderate radii, restrained elevation, tabular operational numbers, visible focus, and reduced motion. The desktop content width is capped at 1600px. Controls are at least 48px where used on tablet.

The interface avoids nested cards, charts, glass effects, heavy gradients, tiny text, dense toolbars, and decorative analytics. Status always combines words with a visual marker. CSS logical behavior and locale direction support Arabic and Badini RTL.
