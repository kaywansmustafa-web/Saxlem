- Doctor Workspace
- Session Status
- Current Patient
- Appointment Context
- Consultation elapsed
- Estimated remaining
- Important appointment note
- Next Patients
- Queue Health: Healthy, Busy, Delayed
- Recent Session Activity
- Pause Session
- Resume Session
- Complete Consultation
- Finish Session

Review must preserve clinical clarity, calm tone, RTL behavior, placeholders, and the difference between pausing a doctor session and managing a receptionist queue.
